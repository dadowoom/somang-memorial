# 소망 추모관 검수 도구 (qa/)

이 PC에 **시험용 서버(가짜 자료)** 를 띄워, 모든 화면을 역할별로 열어 보고, 핵심 흐름을
끝까지 눌러 보고, 격리(다른 가족·방문자가 남의 것을 못 보는지)를 확인하는 도구입니다.
운영(https://somangmemorial.co.kr)에는 연결하지 않습니다. 광양동신·처치크래프트 검수법을
소망 구조에 맞춘 것입니다.

> 시험 자료·결과는 저장소에 올라가지 않습니다(`.qa-local/`, git 무시). 이름은 모두 "시험…",
> 전화는 `010-0000-…`, 메일은 `example.com` 인 가짜만 씁니다.

## 준비물

- **MySQL 8 `mysqld`** (서버 본체). 못 찾으면 `QA_MYSQLD` 에 `mysqld` 위치를 넣습니다.
  포트 **3308** 을 씁니다(3307·43307 은 다른 검수가 쓰므로 피합니다). 서비스로 등록하지 않습니다.
- **Playwright** (화면 순회·흐름용). 저장소에 없으면 이미 설치된 폴더를 `QA_PLAYWRIGHT` 에 넣습니다.
  예: `export QA_PLAYWRIGHT=…/node_modules`. 크로미움이 없으면 이 PC의 Edge(`msedge`)로 자동 전환합니다.
- 저장소 부품 설치: `pnpm install --frozen-lockfile`.

## 한 회차 순서

```bash
node qa/local-server.mjs start --build   # 시험 DB(3308)와 앱(5190)을 켠다. 처음엔 --build
node qa/seed.mjs                          # 가짜 계정·안장 기록·추모관·사진·가족관·초대·편지를 넣는다
node qa/walk.mjs                          # 1) 모든 화면 순회 (읽기만)
node qa/isolation.mjs                     # 2) 격리 확인 (쓰기 시도 — 모두 막혀야 정상)
node qa/seed.mjs --fresh                  # 흐름 전에 자료를 새로 (흐름이 자료를 바꾸므로)
node qa/flows.mjs                         # 3) 끝까지 눌러 보기 (실제 저장)
node qa/local-server.mjs stop             # 끈다
node qa/local-server.mjs reset --yes      # 시험 DB·사진·결과를 모두 지운다(.qa-local 안만)
```

- 셋 다 문제가 없으면 종료 코드 0, 하나라도 있으면 1 입니다(자동 실행에 쓸 수 있습니다).
- 결과는 `.qa-local/results/<시각>-<종류>/` 에 화면 사진과 `*.json` 으로 남습니다.
- `node qa/local-server.mjs restart-app` 은 앱만 다시 켭니다(메모리에만 있는 "여러 번 틀림" 횟수
  제한이 풀립니다). `seed.mjs` 는 넣기 전에 자동으로 이걸 합니다.

## 각 도구가 보는 것

| 도구 | 역할·크기 | 무엇 |
|---|---|---|
| `walk.mjs` | 방문자·가족(주인)·초대받은 가족·다른 가족·관리자·키오스크 × PC(1280)·휴대폰(375), 키오스크는 세로 1080×1920 | 없는 페이지 / API 오류 / 화면 오류 / 가로 넘침 / 로그인 풀림 / 그 역할이 보면 안 되는 글자(비공개 편지·연락처·다른 가족 메일·안장 원문)가 화면·응답에 나오는지 |
| `isolation.mjs` | 방문자·다른 가족·초대받은 가족 | 비공개·작성 중 추모관·사진·편지·연락처를 읽거나 고칠 수 없는지, 남의 사진·편지 번호를 내 추모관 이름으로 바꿔치기할 수 없는지, 관리자 창구가 로그인 없이·일반 회원에게 막히는지, 사진 기한 주소의 서명·기한을 조작하면 막히는지. 끝에 주인 자료가 그대로인지 다시 확인 |
| `flows.mjs` | 준비→신청→처리→결과 | 추모관 만들기(5단계)→사진→등록 완료 / 가족 초대→받기 / 편지→숨기기 / 부모님 찾기 / 관리자 안장 기록 고치기→키오스크 반영 / 비밀번호 변경·다른 기기 로그아웃 / 추억책 / 제작 문의 / 가족관·비공개 사진 기한 주소 |

`QA_HEADED=1 node qa/flows.mjs` 로 브라우저 창을 띄워 눈으로 볼 수 있습니다.
`--only=<이름>` 으로 한 흐름·한 역할만 돌립니다(예: `node qa/flows.mjs --only=letter`).

## 설정값 (qa/lib/env.mjs)

- 포트: `QA_DB_PORT`(기본 3308) · `QA_APP_PORT`(기본 5190). 3307·43307 은 막혀 있습니다.
- 앱은 알림톡·문자·메일·외부 저장소 값을 모두 빈 값으로 덮어 뜨므로, 저장소에 `.env` 가 있어도
  실제 발송은 일어나지 않습니다. 예약 발송(추도일·새 편지 알림)도 꺼진 채로 뜹니다.

## 규칙

- 운영에는 쓰지 않습니다(읽기만). 시험은 이 PC의 `127.0.0.1` 시험 서버에서만 합니다.
- 앱 코드의 버그는 이 도구로 **찾기만** 합니다. 고치기는 따로 승인받습니다.
- 찾은 문제(특히 개인정보·보안)는 공개 저장소가 아니라 담당자 비공개 메모에 적습니다.
