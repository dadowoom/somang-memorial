# Hero verse font

`somang-verse.woff2` is a subset of [Nanum Brush Script](https://fonts.google.com/specimen/Nanum+Brush+Script), containing only the characters in “나는 부활이요 생명이니”.

- Original source: [Google Fonts](https://github.com/google/fonts/blob/main/ofl/nanumbrushscript/NanumBrushScript-Regular.ttf)
- Copyright: NHN Corporation, 2010
- License: SIL Open Font License 1.1, included in `OFL-NanumBrushScript.txt`
- Subsetting: fontTools 4.65.0, WOFF2 output; outlines unchanged
- The subset family is renamed to **Somang Verse**, respecting the reserved font names.

This font is only used for the hero verse. If that text changes, regenerate the subset or use a font containing the new characters.
