# 키오스크 전용 PC 작업 지시문

교회에 놓이는 **키오스크 전용 PC** 에서 작업할 때 먼저 읽는다. 이 PC 의 역할은 하나다 —
**화면에 추모관 키오스크를 전체화면으로 계속 띄워 두는 것.** 개발 PC 가 아니다.

> ⚠️ 이 저장소는 공개다. 서버 주소·계정·비밀번호·DB 정보는 어디에도 적지 않는다.

## 0. 시작하자마자 알아낼 것 (사용자에게 물어보거나 직접 확인)

1. 운영체제와 브라우저 (윈도우 11? 엣지? 크롬?)
2. **터치스크린인지** — 키오스크 화면은 터치 전제다
3. 지금 브라우저가 **어떤 주소**로 설정돼 있는지 — **IP 주소(`115.68…:3050`)면 반드시 바꾼다.**
   그 문은 2026-09-13 에 닫혔다. IP 로 두면 화면이 안 뜬다.
4. 인터넷이 되는지 — 키오스크는 서버에서 화면을 받아온다. 오프라인이면 동작하지 않는다.

## 1. 키오스크가 띄울 주소

```
https://somangmemorial.co.kr/kiosk
```

- 반드시 `https` + 도메인. `http` 나 IP 는 쓰지 않는다.
- 추모관 하나만 고정해서 보여줄 때는 `https://somangmemorial.co.kr/kiosk/memorial/<추모관주소>`

## 2. 브라우저를 키오스크 모드로

엣지(윈도우 기본) 기준. 바로가기 대상에 아래처럼 넣거나, 시작 프로그램에 등록한다.

```
msedge.exe --kiosk https://somangmemorial.co.kr/kiosk --edge-kiosk-type=fullscreen --no-first-run
```

크롬이면:

```
chrome.exe --kiosk https://somangmemorial.co.kr/kiosk --no-first-run --disable-pinch --overscroll-history-navigation=0
```

이 모드에서는 주소창·탭·닫기 버튼이 없다. 빠져나오려면 키보드로 `Alt+F4`.

## 3. PC 자체 설정 — 하나라도 빠지면 며칠 뒤 화면이 꺼져 있다

| 항목 | 해야 할 것 |
|---|---|
| 절전 | 화면 끄기·절전 모드 **안 함** (전원 옵션) |
| 화면 보호기 | 끔 |
| 자동 로그인 | 부팅하면 사람 없이 바로 바탕화면까지 |
| 자동 시작 | 로그인 뒤 키오스크 브라우저가 스스로 뜨게 (시작 프로그램 폴더 또는 작업 스케줄러) |
| 윈도우 업데이트 | 재시작 시간을 새벽으로. 낮에 예배 중 재부팅되면 안 된다 |
| 터치 제스처 | 화면 가장자리 스와이프(알림·작업 보기) 끔. 조문객이 실수로 바탕화면으로 나간다 |
| 알림 | 집중 지원(방해 금지) 켬. 팝업이 부고 화면 위에 뜨면 안 된다 |
| 소리 | 필요 없으면 음소거 |

## 4. 설정 뒤 반드시 눌러서 확인할 것

앱에 키오스크용 장치가 들어 있다. 하나씩 실제로 확인한다.

- [ ] 첫 화면이 뜨고 **화상 키보드**가 검색칸을 누르면 올라온다 (앱 자체 키보드다, 윈도우 것이 아니다)
- [ ] 이름으로 검색 → 추모관이 열린다
- [ ] **90초** 아무것도 안 하면 처음 화면으로 돌아간다 (`KIOSK_IDLE_RESET_MS`)
- [ ] 비공개 추모관은 목록에 **안 보인다** (#63)
- [ ] 인터넷 선을 잠깐 뽑았을 때 흰 화면이 아니라 **안내 문구**가 뜨고, 꽂으면 돌아온다
- [ ] 편지 남기기가 되고, 두 번 연달아 눌러도 두 번 저장되지 않는다
- [ ] 화면을 위아래로 세게 밀어도 브라우저 밖으로 안 나간다
- [ ] PC 를 껐다 켜면 사람 손 없이 키오스크 화면까지 스스로 온다 ← **이게 제일 중요**

## 5. 이 PC 에서 코드 작업도 해야 한다면

가능하면 하지 않는다. 꼭 해야 하면:

- 저장소는 따로 받는다. 키오스크 브라우저와 섞지 않는다.
  ```bash
  git clone https://github.com/dadowoom/somang-memorial.git
  ```
- 그 다음은 [HANDOVER.md](HANDOVER.md) 그대로 — 시작할 때 `git fetch`, 끝나면 `push`,
  `main` 직접 push 금지, PR 전 검사·시험·빌드.
- 개발 서버(`pnpm run dev`)를 이 PC 에서 띄운 채로 두지 않는다. 키오스크가 그 주소를 보게 되는 사고가 난다.
- **이 PC 에서 운영 서버 배포는 하지 않는다.** 배포는 서버 접속 열쇠가 있는 PC 에서만.

## 6. 하지 말 것

- 키오스크 주소를 IP 나 `http` 로 두는 것
- 브라우저 일반 창으로 띄워 두는 것 (조문객이 다른 사이트로 나간다)
- 이 PC 에 서버 비밀번호·열쇠 파일을 두는 것 — 공공장소에 놓이는 PC 다
- 절전·업데이트 설정을 "나중에" 로 미루는 것

## 7. 문제가 생기면

- 화면이 흰색/오류 → 먼저 **인터넷**, 그다음 **주소가 도메인인지** 확인
- 화면은 뜨는데 자료가 없다 → 서버 문제일 수 있다. 다른 폰에서 `https://somangmemorial.co.kr` 이 열리는지 본다
- 이 문서로 해결 안 되면 서버 쪽 사람에게 넘긴다. 이 PC 에서 서버를 고치려 하지 않는다
