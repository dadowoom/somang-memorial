# 키오스크 전용 PC 에서 작업을 시작할 때

교회 키오스크 PC 에서 Claude(또는 Codex) 세션을 열었을 때 **맨 먼저 읽는 문서**다.
이 PC 의 역할은 하나 — **추모관 키오스크 화면을 전체화면으로 계속 띄워 두는 것.**

> ⚠️ 이 저장소는 공개다. 서버 주소·계정·비밀번호·DB 정보는 어디에도 적지 않는다.
> 공공장소에 놓이는 PC 이므로 서버 접속 열쇠도 이 PC 에 두지 않는다.

## 1. 키오스크를 세팅하려면 → [KIOSK_SETUP.md](KIOSK_SETUP.md)

설정 절차·스크립트·확인 목록은 **그 문서가 원본**이다. 여기 다시 적지 않는다.

- 실행 파일: `scripts/kiosk/setup-kiosk.ps1` (관리자 PowerShell 에서 한 번)
- 띄우는 주소: `https://somangmemorial.co.kr/kiosk` — **반드시 https + 도메인**
- 옛 IP 주소(`115.68…:3050`)는 2026-09-13 에 닫혔다. 어디에 남아 있으면 화면이 안 뜬다.
  기존 바로가기·`C:\Kiosk\config.json` 에 IP 가 있으면 먼저 바꾼다.

## 2. 시작하자마자 확인해서 보고할 것

1. 윈도우 버전(Home/Pro)과 브라우저 — 스크립트는 엣지 기준이다
2. **터치스크린인지** — 앱은 자체 화상 키보드를 쓴다 (윈도우 것이 아니다)
3. 지금 키오스크가 **어떤 주소로 설정돼 있는지** — IP 면 1번대로 바꾼다
4. 인터넷이 되는지 — 키오스크는 서버에서 화면을 받아온다
5. **모니터가 세로인지**, 윈도우 디스플레이 방향이 `세로` 로 돼 있는지 — 수양관 키오스크는 세로 모니터다.
   앱은 세로(1080×1920)에서 동작 확인됐다(2026-09-13). 가로로 뜨면 앱이 아니라 윈도우 화면 방향 문제다

## 3. 세팅 뒤 반드시 눌러서 확인 (앱에 들어 있는 장치들)

- [ ] 화면이 **세로로 꽉 차게** 뜬다 (KIOSK_SETUP.md 의 '세로 모니터' 절)
- [ ] 검색칸을 누르면 앱 화상 키보드가 올라온다
- [ ] **90초** 방치하면 처음 화면으로 돌아간다 (`KIOSK_IDLE_RESET_MS`)
- [ ] 비공개 추모관은 목록에 안 보인다 (#63)
- [ ] 인터넷을 잠깐 끊으면 흰 화면이 아니라 안내 문구가 뜨고, 다시 잇으면 돌아온다
- [ ] 편지를 두 번 연달아 눌러도 한 번만 저장된다
- [ ] **PC 를 껐다 켜면 사람 손 없이 키오스크 화면까지 스스로 온다** ← 제일 중요

## 4. 이 PC 에서 코드 작업도 해야 한다면

가능하면 하지 않는다. 꼭 해야 하면 [HANDOVER.md](HANDOVER.md) 규칙 그대로:
시작할 때 `git fetch`, 끝나면 `push`, `main` 직접 push 금지, PR 전 검사·시험·빌드.

- 개발 서버(`pnpm run dev`)를 띄운 채 두지 않는다. 키오스크 브라우저가 그 주소를 보게 되는 사고가 난다.
- **운영 서버 배포는 이 PC 에서 하지 않는다.** 접속 열쇠가 있는 PC 에서만.

## 5. 문제가 생기면

- 화면이 흰색/오류 → **인터넷** → **주소가 https 도메인인지** 순서로 본다
- 화면은 뜨는데 자료가 없다 → 다른 폰에서 `https://somangmemorial.co.kr` 이 열리는지 본다. 열리면 PC 문제, 안 열리면 서버 문제
- 서버 문제는 이 PC 에서 고치려 하지 말고 서버 쪽 사람에게 넘긴다
