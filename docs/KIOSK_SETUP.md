# 키오스크 PC 설정 안내

수양관에 두는 키오스크 PC 를 **켜면 바로 추모관 검색 화면이 전체 화면으로** 뜨게 만드는
방법이다. 컴퓨터를 잘 몰라도 따라 할 수 있게 적었다. 한 번만 하면 된다.

설정이 끝나면 이렇게 된다.

- PC 전원을 켜면 비밀번호 입력 없이 자동으로 로그인된다.
- 로그인되자마자 **Google Chrome** 으로 추모관 검색 화면이 전체 화면으로 뜬다. 주소창·메뉴가 안 보인다.
- 누가 브라우저를 닫아도 3초 뒤 다시 뜬다. Chrome 이 켜지자마자 꺼지기를 되풀이하면 다시 켜기 전에
  10초·30초·60초로 기다리는 시간을 늘린다.
- 실행기(`C:\Kiosk\start-kiosk.ps1`)는 한 번에 하나만 돈다. 여러 번 실행돼도 나중 것은 바로 끝난다.
  이 Chrome 이 이미 떠 있으면(Windows 가 다시 열었거나 Chrome 이 업데이트하며 스스로 다시 켠 경우)
  하나 더 켜지 않고 그 Chrome 을 지켜본다. (2026-10-07 현장에서 실행기가 둘이 돌아 첫 화면이 3~5초마다
  새로 뜨고 광고가 나오지 않았다.)
- 화면이 꺼지거나 절전에 들어가지 않는다.
- **Windows 자동 업데이트를 끈다** (2026-10-07). 드라이버 자동 교체와 업데이트 때문의 재시작도 막는다.
  보안 패치는 몇 달에 한 번 관리자가 직접 설치한다 — 아래 '윈도우 업데이트' 절. 활성 시간은 08~22시.
- 아무도 안 만지면 검색 화면으로 되돌아간다 (검색 화면 90초, 추모관 화면 3분 — 끝나기
  30초 전에 "잠시 뒤 처음 화면으로 돌아갑니다" 안내가 뜬다. 영상 재생 중 15분). 이건 추모관 앱이 한다.
- 인터넷이 끊기면 화면 위에 빨간 띠가 뜨고, 다시 이어지면 저절로 사라지며 자료를 다시 불러온다.

## 준비물

| 준비물 | 설명 |
|---|---|
| Windows 10 또는 11 PC | Home 이든 Pro 든 상관없다. |
| Google Chrome | 모든 사용자용으로 설치한다. 관리자 개인 계정에만 설치하면 `kiosk` 계정이 실행할 수 없다. |
| 터치 모니터 (권장) | 화면에 키보드가 뜨므로 실물 키보드는 없어도 된다. 터치가 아니면 마우스로도 쓸 수 있다. |
| 인터넷 | 유선이 안정적이다. 무선이면 자동으로 다시 연결되는지 확인한다. |
| 관리자 계정 비밀번호 | 이 PC 의 Windows 관리자 계정으로 설정을 실행한다. |

## 오늘 화면만 체험하기

아래 설정 파일을 받은 뒤 일반 PowerShell에서 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\setup-kiosk.ps1" -Preview
```

Chrome이 별도 미리보기 프로필의 시크릿 창으로 공식 HTTPS 화면을 연다. **Alt+F4**로 종료한다.
미리보기는 계정·자동 로그인·예약 작업·전원·화면 방향을 변경하지 않고, 닫아도 다시 열리지 않는다.
기존 개인 Chrome 창과 프로필을 재사용하지 않는다.
모니터를 내일 연결한다면 오늘은 가로 화면 그대로 체험하고, 연결 후 아래 세로 설정을 진행한다.

## 자동 실행 설정하기

전용 로컬 계정 생성, 자동 로그인 비밀번호의 레지스트리 저장, `SomangKiosk` 예약 작업,
화면 꺼짐·절전·최대절전 해제, Windows 자동 업데이트 끄기(드라이버 자동 교체·업데이트 재시작 포함)와
업데이트 활성 시간 변경을 **승인받은 뒤** 진행한다.
Chrome 로그인·동기화·비밀번호/자동완성 저장·알림·번역·백그라운드 실행 정책은
이 PC의 모든 Chrome 사용자에게 적용된다. 기존 Edge 정책과 프로필은 삭제하지 않는다.

1. 키오스크 PC 에서 **관리자 계정으로** 로그인한다.
2. 설정 파일을 내려받는다. Chrome 을 열고 아래 주소로 간다.

   ```
   https://raw.githubusercontent.com/dadowoom/somang-memorial/main/scripts/kiosk/setup-kiosk.ps1
   ```

   글자가 가득한 화면이 나오면 **Ctrl+S** 로 저장한다. 저장 위치는 **다운로드**, 파일 이름은
   `setup-kiosk.ps1` 그대로 둔다. (이름 뒤에 `.txt` 가 붙으면 안 된다.)
3. **시작** 버튼을 마우스 오른쪽으로 누르고 **Windows PowerShell(관리자)** 또는
   **터미널(관리자)** 을 연다. "변경을 허용하시겠습니까?" 가 뜨면 **예**.
4. 아래 두 줄을 한 줄씩 붙여넣고 Enter 를 친다.

   ```
   Set-ExecutionPolicy -Scope Process Bypass -Force
   & "$env:USERPROFILE\Downloads\setup-kiosk.ps1"
   ```

5. **키오스크 전용 비밀번호**를 정하라고 나온다. 이 PC 에서만 쓰는 간단한 것을 넣는다.
   (자동 로그인을 위해 PC 안에 저장되므로 다른 곳에서 쓰는 비밀번호는 넣지 않는다.)
6. `완료` 가 나오면 설정이 끝난다. 스크립트는 자동으로 재부팅하지 않는다.
7. 진행 중인 작업을 저장하고 승인을 받은 뒤 시작 메뉴에서 다시 시작한다.
   PC 가 다시 켜지면서 자동으로 로그인되고, Chrome으로 추모관 검색 화면이 전체 화면으로 뜨는지 확인한다.

### 실행기만 새로 고칠 때 (다시 설치)

실행기가 바뀌었을 때(예: 2026-10-07 "실행기 하나만 돌기")는 위 1~4번을 그대로 하되, 4번의 둘째 줄 끝에
`-SkipAutoLogon` 을 붙인다. 그러면 `kiosk` 계정과 비밀번호·자동 로그인은 건드리지 않고
실행기·예약 작업·Chrome 정책·전원·Windows 업데이트 설정만 새로 쓴다. 비밀번호를 다시 넣으라는 질문도 나오지 않는다.

```
Set-ExecutionPolicy -Scope Process Bypass -Force
& "$env:USERPROFILE\Downloads\setup-kiosk.ps1" -SkipAutoLogon
```

`완료` 가 나오면 **PC 를 다시 시작한다.** 이미 돌고 있던 옛 실행기는 다시 시작해야 없어진다.

## 세로 모니터라면 (수양관 키오스크는 세로다)

키오스크 화면은 **세로(1080×1920)에서도 그대로 동작한다** — 2026-09-13 에 검색 화면과
추모관 상세 화면을 세로 비율로 열어 가로 넘침·잘림이 없는 것을 확인했다.
앱 쪽에서 할 일은 없고, **윈도우 화면 방향만 세로로 돌리면** 된다.
Chrome 전체화면은 바탕화면 방향을 그대로 따른다. 모니터를 연결한 뒤 설정한다.

1. 관리자 계정으로 로그인 → 바탕화면 오른쪽 클릭 → **디스플레이 설정**
2. **디스플레이 방향** 을 `세로` (모니터가 거꾸로 걸려 있으면 `세로(대칭 이동)`) 로 바꾸고 **변경 유지**
3. 해상도 **1080×1920**, 배율 **100%**로 맞추고 `kiosk` 계정에서도 세로로 뜨는지 확인한다
4. 그래도 가로로 뜨면 그래픽 드라이버 설정(인텔/엔비디아 제어판)이 방향을 다시 덮어쓰는 것이다.
   거기서도 세로로 맞춘다

터치스크린이면 방향을 돌린 뒤 **터치 좌표가 화면과 맞는지** 반드시 눌러 본다. 어긋나면
`제어부 → 태블릿 PC 설정 → 보정` 을 한 번 한다.

### 현장에 못 갈 때: 관리자 화면의 "키오스크 세로 고정" (2026-10-03)

윈도우 화면 방향 설정이 풀려 글자가 옆으로 누워 보이면, 현장에 가기 전에
**관리자 → 키오스크 화면(/admin/kiosk) → 키오스크 세로 고정 → 켬** 을 누른다.

- 키오스크 창이 **가로일 때만** 화면 전체를 90° 돌려 세로로 그린다. 창이 이미 세로면
  (윈도우 설정이 제대로면) 켜 두어도 아무것도 바뀌지 않는다. 이중으로 돌지 않는다.
- 켜져 있는 키오스크는 보통 **2분 안에** 따라온다. 재배포·재부팅이 필요 없다.
- 거꾸로 보이면 방향을 **시계 방향 / 반시계 방향(기본)** 중 다른 쪽으로 바꾼다.
- 같은 화면 아래 "키오스크가 알려 온 화면 상태"에 마지막 접속 시각·창 크기(예: 1920×1080(가로))·
  적용 여부가 보인다. 키오스크가 5분마다 알린다. 로그인 없이 받는 참고 정보다.
- 시험·응급용 주소: `/kiosk?rotate=ccw`, `?rotate=cw`(설정과 상관없이 돌림),
  `?rotate=off`(돌리지 않음), `?rotate=auto`(덮어쓰기 지우고 설정 따름). 같은 탭에서는 유지된다.
- 설정은 DB 가 아니라 서버 업로드 폴더의 숨김 파일(`.settings/kiosk-display.json`)에
  남는다. 밖에서 열 수 없고 배포해도 그대로다.
- 이것은 **임시 조치**다. 다음에 현장에 가면 위 1~4 대로 윈도우 방향을 세로로 되돌리고
  터치 위치를 확인한 뒤 관리자 화면에서 **끔** 으로 돌려 둔다.

동작 방식: 바깥 창이 같은 키오스크 화면을 틀(iframe) 하나에 담아 돌린다. 틀 안은 처음부터
세로 창(1080×1920)이라 자판·안내 창·문의 창·처음으로 단추·연결 끊김 띠가 모두 세로 키오스크와
똑같이 뜬다. 크롬은 돌린 화면에서 "가로 넘침 숨김" 칸의 손가락 밀기를 무시하므로, 틀 안에서만
`overflow-x` 를 `auto` 로 둔다(index.css). 틀이 20초 안에 뜨지 않으면 바깥 창이 다시 불러온다.

## 잘 됐는지 확인

- [ ] 화면이 **세로로 꽉 차게** 뜬다. 가로로 뜨거나 옆에 검은 띠가 있으면 위 '세로 모니터' 절을 본다
- [ ] PC 를 껐다 켜면 비밀번호 없이 검색 화면이 뜬다.
- [ ] 성함을 넣고 검색이 된다. 화면 키보드가 뜬다.
- [ ] 사진·영상, 홈 복귀, 화면 네 모서리와 자판의 실제 터치 좌표가 맞는다.
- [ ] 검색 화면에서 90초, 추모관 화면에서 3분 두면 검색 화면으로 돌아간다 (추모관 화면은 30초 전 안내가 뜬다).
- [ ] 랜선을 잠깐 뽑으면 빨간 띠가 뜨고, 꽂으면 사라진다 (승인 후 시험).
- [ ] 30분 이상 두어도 화면이 꺼지지 않는다.
- [ ] (실물 키보드가 있으면) Alt+F4 로 닫아도 3초 뒤 다시 뜬다.
- [ ] PC 를 다시 시작한 뒤 첫 화면이 가만히 있고(몇 초마다 새로 뜨지 않고), 아무도 안 만지면 30초 뒤 광고가 나온다.

## 관리가 필요할 때

키오스크 화면에서 빠져나와 PC 를 손봐야 하면:

1. 실물 키보드를 꽂고 **Ctrl+Alt+Del** 을 누른다.
2. **로그아웃** 을 누른다.
3. 로그인 화면에서 **관리자 계정**을 골라 로그인한다.

관리 작업을 저장하고 재부팅 승인을 받은 뒤 다시 시작하면 `kiosk` 계정으로 자동 로그인된다.
로그아웃만으로 자동 로그인이 보장되지는 않는다.

새 버전을 배포한 뒤에는 키오스크를 손볼 필요가 없다. 화면이 5분마다 서버의 화면 파일을
확인해 달라졌으면 손님이 없을 때 스스로 새로고침하고, 매일 새벽 4시대에도 한 번 새로고침한다.
인터넷이 끊겨 있으면 새로고침하지 않는다. (앱 코드 `client/src/lib/kioskAutoReload.ts`)

## 윈도우 업데이트 (자동으로 하지 않는다)

2026-10-07 현장 결정. 업데이트가 깔리거나 그 뒤 재시작될 때 그래픽(AMD) 드라이버가 바뀌어 세로
1080×1920 설정이 풀리거나(화면이 눌리고 돌아감), Windows 가 Chrome 을 다시 열어 첫 화면이 되풀이됐다.
그래서 설정 파일이 아래 세 값을 넣는다. (수양관 키오스크에는 같은 날 관리자 PowerShell 에서 `reg add` 로 직접 넣었다.)

| 값 | 위치 | 뜻 |
|---|---|---|
| `NoAutoUpdate = 1` | `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU` | 자동 업데이트 끄기. 관리자가 "업데이트 확인"을 누를 때만 받는다 |
| `ExcludeWUDriversInQualityUpdate = 1` | `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate` | 장치 드라이버를 Windows 업데이트로 바꾸지 않기 |
| `NoAutoRebootWithLoggedOnUsers = 1` | `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU` | 로그인돼 있는 동안 업데이트 때문에 저절로 재시작하지 않기 |

**보안 패치는 몇 달에 한 번 직접 설치한다.** 손님이 없는 날을 정해서:

1. 위 '관리가 필요할 때' 대로 관리자 계정으로 로그인한다.
2. **설정 → Windows 업데이트 → 업데이트 확인** → 설치가 끝나면 **다시 시작**.
3. 다시 켜진 뒤 화면이 세로로 꽉 차는지, 첫 화면이 가만히 있다가 30초 뒤 광고가 나오는지 본다.
   화면이 눌리거나 돌아가 보이면 위 '세로 모니터' 절대로 AMD 사용자 지정 해상도 1080×1920 을 다시 만든다.

Chrome 은 이와 별개로 스스로 업데이트한다(브라우저 보안). 실행기가 그때 Chrome 이 스스로 다시 켜져도 하나 더 켜지 않는다.

## 주소가 바뀌었을 때

관리자 계정으로 로그인해서 `C:\Kiosk\config.json` 을 메모장으로 열고 `url` 의 값을 새
주소로 바꾼다. 예:

```json
{ "url": "https://새주소/kiosk" }
```

저장하고 PC 를 다시 시작하면 된다. 또는 설정 파일을 다시 실행해도 된다.

```
& "$env:USERPROFILE\Downloads\setup-kiosk.ps1" -KioskUrl "https://새주소/kiosk"
```

## 문제가 생기면

| 화면이 옆으로 눌리거나 돌아가 보인다 | 모니터가 세로 화면인데 가로(1920×1080)라고 자기를 소개하는 제품이라, 윈도우가 모니터를 새로 알아보면(모니터만 껐다 켬, 모니터가 PC 보다 늦게 켜짐, 절전에서 깨어남) AMD 로 만든 세로 1080×1920 대신 가로 값으로 돌아갈 수 있다. PC 를 다시 시작하면 돌아온다. 모니터와 PC 를 같은 멀티탭에 꽂고 모니터 자체 절전을 끈다. 위 '세로 모니터' 절. |
| "복원하시겠습니까?" 창이 뜬다 | 설정 파일을 다시 실행한다. 실행기가 이 창을 막도록 되어 있다. |
| 화면이 꺼진다 | 모니터 자체의 절전 설정을 본다. PC 쪽은 설정 파일이 껐다. |
| 관리자 계정으로 로그인이 안 된다 | Ctrl+Alt+Del → 로그아웃 뒤 로그인 화면 왼쪽 아래 "다른 사용자" 를 고른다. |

## 이 방식의 한계와 다음 단계

이 설정은 **어느 Windows 에서나** 되게 만든 것이다. 다만 실물 키보드를 꽂으면
Ctrl+Alt+Del 이나 Windows 키가 막히지는 않는다. 수양관처럼 사람이 드나드는 곳에
두는 데는 이 정도로 충분하다.

이 문서는 **Chrome + 전용 일반 계정 + 예약 작업** 방식이다.
Windows의 단일 앱 할당된 액세스에서 Edge를 선택하는 방식과 혼용하지 않는다.
더 강한 PC 잠금이 필요하면 Windows 에디션과 조직 정책에 맞는 별도 설계를 먼저 검토한다.

기존 Edge 방식에서 전환할 때는 작업을 저장하고 `kiosk` 계정을 먼저 로그아웃한다.
관리자 계정에서 이 스크립트를 실행하면 `SomangKiosk` 작업과 실행기가 Chrome용으로 교체된다.
기존 `EdgeProfile`과 Edge 정책은 보존하며, 새 `ChromeProfile`을 사용한다.
90초 초기화는 브라우저 옵션이 아니라 추모관 앱이 처리한다.

## 화면 오른쪽 아래 동그라미 단추 (2026-09-16)

검색 화면 오른쪽 아래(5시 방향)에 세로로 단추 세 개가 있다.

- **예시 보기** — 추모관이 어떤 모습인지 견본 추모관을 연다. 어느 추모관을 보여 줄지는
  `client/src/lib/kioskQuickActions.ts` 의 `KIOSK_SAMPLE_MEMORIAL_SLUG` 한 줄로 정한다.
- **이용 안내** — 홈페이지 이용 안내 본문을 그대로 보여 준다(다른 화면으로 가는 단추만 뺌). "확인했습니다"로 닫는다.
- **문의** — 화면 반반. 왼쪽은 소망교회 경조부 전화번호 안내, 오른쪽은 추모관 제작 업체 문의:
  관람객이 전화번호(성함은 선택)를 남기면 서버가 `INQUIRY_NOTIFY_EMAIL` 로 메일을 보내고,
  관리자 화면 → 운영 → "문의"에도 남는다(메일이 실패해도). 문구·전화번호는
  `client/src/lib/kioskInquiry.ts` 에서 바꾼다. 홈페이지의 "문의하기"(이용 안내 인생화원 칸,
  예시 추모관 5시 방향 동그라미)도 같은 곳으로 접수되고 "홈페이지"로 구분된다(2026-09-17).

자판이 올라와 있거나 광고 화면일 때는 보이지 않는다. 잠시 만지지 않으면 안내 창도 같이 닫힌다.

왼쪽 아래(7시 방향)에는 화면을 내렸을 때만 보이는 **맨 위로** 단추가 있다(검색 화면·추모관 화면 모두).
광고(대기) 화면은 **5분 동안 아무도 만지지 않았을 때만** 시작한다. 처음 켰을 때나 "처음으로"를
누른 직후에는 검색 화면이 먼저 나온다 (2026-09-16 결정).
