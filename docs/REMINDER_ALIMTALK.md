# 추도일 알림을 카카오톡으로 보내기 (2026-09-17 결정, 진행 전)

추도일 알림을 문자 대신 **카카오 알림톡**으로 보내기로 했다. 알림을 신청한 분이 휴대폰
번호만 넣으면 그 번호로 가입된 카카오톡으로 알림이 간다. 채널을 친구로 추가할 필요는 없다.
2026-09-17 에 준비 절차와 문구 초안까지 정하고 **"문자는 나중에 하자"** 로 멈췄다.
이 문서는 그 자리에서 다시 시작하기 위한 것이다.

> ⚠️ 이 저장소는 공개다. 알리고 API 키·Senderkey·알리고 계정 아이디·서버 주소는 이 문서에도
> 적지 않는다. 캡처나 채팅에도 올리지 않는다. 그런 값은 서버의 `.env` 에만 둔다.

## 1. 지금 상태 (2026-09-23)

- 추모관 화면의 추도일 알림 신청 칸은 **아직 숨겨져 있다.**
  `shared/featureFlags.ts` 의 `MEMORIAL_REMINDER_SIGNUP_ENABLED = false`.
- @인생화원 발신프로필: **정상** (휴면 풀림). 풀린 뒤 30일 안에 한 번은 보내야 한다.
- 템플릿 3개 등록, **카카오 검수중** (2026-09-23).

  | 템플릿 코드 | 템플릿명 | 서버 설정 이름 |
  |---|---|---|
  | `UL_7251` | 추도일 알림 신청 완료 | `ALIGO_TPL_REMINDER_CONFIRM` |
  | `UL_7253` | 추도일 하루 전 알림 | `ALIGO_TPL_REMINDER_DAY_BEFORE` |
  | `UL_7254` | 알림 인증번호 (보안 템플릿) | `ALIGO_TPL_VERIFY_CODE` |

- 서버 코드는 **솔라피 문자 대신 알리고 알림톡**으로 보낸다 (`server/_core/alimtalk.ts`).
  신청 확인, 하루 전 알림, 관리자 시험 발송(관리자 → 운영 → 알림톡 발송 설정)이 알림톡을 쓴다.
  문구는 검수받은 템플릿과 글자까지 같은지 `server/_core/alimtalk.test.ts` 가 확인한다.
- 본인 번호 확인 (#168): 신청할 때 그 번호로 인증번호(문구 3)를 보내고 맞아야 저장한다.
  번호·인증번호는 해시만 `reminder_phone_verifications` 에 둔다 (5분, 5번, 하루 뒤 삭제).
- 알림 그만 받기: `/memorial/<주소>?reminder=stop` 을 열면 추모관 대신 "알림 그만 받기" 칸이
  나온다(비공개 추모관이어도). 번호 → 인증번호 → 신청 기록(전화번호)을 지운다. 신청 칸을
  꺼 두어도 해지는 언제나 된다.
- 하루 전 알림 보내는 방식 (2026-09-23): 매시간 살펴보고 **서울 9시~20시**에만 보낸다.
  한 분씩 "올해 보냄"을 **먼저 찍고** 보내서 두 번 가지 않는다. 실패하면 표시를 되돌려
  다음 시간에 다시 보낸다. 추도일은 지금 추모관에 적힌 값을 쓰고, **음력이면 보내지 않는다.**
  규칙: `server/reminderSchedule.ts`
- 남은 코드 작업:
  - 개인정보처리방침 위탁 표 (알리고 운영사, 카카오 추가, 솔라피 정리).

## 2. 정한 것

| 항목 | 결정 |
|---|---|
| 보내는 방식 | 카카오 알림톡 |
| 보내는 채널 | 제작 업체의 **인생화원** 채널 (`@인생화원`). 카톡에서 보내는 사람이 "인생화원"으로 보인다 |
| 발송 업체 | **알리고**. 인생화원 채널이 2025-07 부터 알리고에 연결돼 있다 |

- 인생화원 채널은 카카오 비즈니스 인증을 이미 받았다(채널 이름 옆 파란 체크).
  채널 공개·검색 허용이 켜져 있고 고객센터 연락처도 들어가 있다.
- 솔라피는 쓰지 않는다. 솔라피 안내상 다른 곳에 연결된 채널은 솔라피에 연동되지 않는다.
  (솔라피 계정은 2026-09-17 에 가입만 해 두었다.)

## 3. 사람이 할 일 (알리고 사이트)

1. **발신프로필 휴면 해제.** 알리고 → 카카오톡 → 카카오채널 관리에 `@인생화원 (휴면)` 으로
   나온다. 1년 동안 알림톡을 보내지 않아서다. 휴면이면 템플릿 등록 화면에서 채널을 고를 수 없다.
   - 먼저 "채널상태 갱신" 을 눌러 본다.
   - 그래도 휴면이면 알리고 고객센터(02-511-4560, cs@alipeople.kr)에 해제를 요청한다.
     "알리고 아이디 ___ 에 등록된 카카오채널 @인생화원의 발신프로필 휴면 해제를 부탁드립니다."
   - 휴면을 푼 뒤 **30일 안에 알림톡을 한 번도 보내지 않으면 다시 휴면**이 된다.
     4~6번과 코드 작업을 그 안에 끝내고 시험 발송을 한 번 한다.
   - 휴면인 채로 1년이 지나면 발신프로필이 지워져 새로 등록해야 한다.
2. **템플릿 3개 등록 → 검수 요청.** 카카오톡 → 템플릿관리. 아래 4장의 문구를 글자 그대로
   넣는다. 템플릿 등록 대행은 "직접입력", 강조유형은 "기본형". 알리고 안내로 검수는 영업일 4~5일.
   **통과한 문구는 고칠 수 없다.**
3. **API 키 발급 + 발송 서버 IP 등록.** 알리고 문자API 메뉴. IP 는 운영 서버의 공인 IP.
4. **발신번호 등록.** 알리고 발송 요청에는 발신자 연락처(`sender`)가 필수이고, 미리 등록한
   번호만 쓸 수 있다. 관리자 휴대폰 번호를 휴대폰 인증으로 등록한다. 실패 시 대체 문자
   (`failover`)를 끄면 받는 분께 이 번호는 보이지 않는다.
5. **포인트 충전.** 2026-09-17 기준 잔여포인트 0.
6. 검수가 끝나면 **템플릿 코드 3개**를 개발 쪽에 알려 준다. 템플릿 코드는 비밀값이 아니다.

## 4. 템플릿 초안 (검수에 올릴 문구)

변수에 들어갈 값:

| 변수 | 들어갈 값 | 예 |
|---|---|---|
| `#{고인}` | 성함 + 직분 | 김소망 권사 |
| `#{추도일}` | 신청 때 저장한 추도일 (`memorial_reminder_subscriptions.memorialDay`) | 매년 05월 22일 |
| `#{추모관주소}` | 추모관 주소 이름(slug) | kim-somang-kwonsa |
| `#{인증번호}` | 6자리 숫자 | 482913 |

### 문구 1. 템플릿명: 추도일 알림 신청 완료

```text
[소망이 있는 곳]
#{고인}님 추도일 알림 신청이 완료되었습니다.

추도일: #{추도일}
추도일 하루 전 카카오톡으로 알려 드립니다.

소망교회 온라인 추모관에서 추도일 알림을 신청하신 분께 보내는 안내입니다.
```

### 문구 2. 템플릿명: 추도일 하루 전 알림

```text
[소망이 있는 곳]
내일은 #{고인}님의 추도일입니다.

추도일: #{추도일}
고인의 삶과 믿음을 기억하며 조용히 마음을 전해 보세요.

소망교회 온라인 추모관에서 추도일 알림을 신청하신 분께 보내는 안내입니다.
```

문구 1·2 버튼 (웹링크 두 개, 모바일·PC 링크 같게):

| 버튼 이름 | 링크 |
|---|---|
| 추모관 보기 | `https://somangmemorial.co.kr/memorial/#{추모관주소}` |
| 알림 그만 받기 | `https://somangmemorial.co.kr/memorial/#{추모관주소}?reminder=stop` |

### 문구 3. 템플릿명: 알림 인증번호

```text
[소망이 있는 곳]
인증번호는 #{인증번호}입니다.

추도일 알림 신청이나 해지를 위해 요청하신 번호입니다. 요청하지 않으셨다면 이 메시지는 무시해 주세요.
```

버튼 없음. 보안 템플릿 선택이 있으면 켠다.

## 5. 코드에서 할 일 (템플릿 코드가 나온 뒤)

- **알리고 알림톡 발송 모듈.** `POST https://kakaoapi.aligo.in/akv10/alimtalk/send/`
  - 필수: `apikey`, `userid`, `senderkey`, `tpl_code`, `sender`, `receiver_1`, `subject_1`, `message_1`
  - 선택: `button_1` (JSON, 템플릿에 등록한 버튼과 같게), `failover=N`, `testMode`
  - `message_1` 은 검수 통과한 문구와 **글자·줄바꿈까지 같아야** 한다. 변수 자리만 바뀐다.
  - 응답 `code` 가 0 이면 성공. 실패 사유는 서버 로그에만 남기고 화면에는 쉬운 말로.
- **설정값 이름(제안).** `.env.example` 에는 이름만 넣는다.
  `ALIGO_API_KEY`, `ALIGO_USER_ID`, `ALIGO_SENDER_KEY`, `ALIGO_SENDER`,
  `ALIGO_TPL_REMINDER_CONFIRM`, `ALIGO_TPL_REMINDER_DAY_BEFORE`, `ALIGO_TPL_VERIFY_CODE`
- **본인 번호 확인.** 신청할 때 인증번호(문구 3)를 보내고, 맞게 넣어야 신청이 저장되게 한다.
  시도 횟수 제한을 둔다.
- **알림 그만 받기.** `/memorial/<주소>?reminder=stop` 에서 번호 + 인증번호로 그 추모관 알림을 취소.
- **확인 문자 문구.** "테스트 기간" 문구를 없애고 문구 1로 바꾼다.
- **보내는 날.** `REMINDER_DAYS_BEFORE` 는 1 로 둔다. 문구 2가 "내일은" 이다.
- **개인정보처리방침** (`client/src/pages/PrivacyPolicy.tsx`) 위탁 표. 알리고 운영사, 제작 업체,
  카카오를 더하고 솔라피 줄을 정리한다. 각 회사의 정식 상호를 확인해서 넣는다.
- **켜기.** 다 되면 `MEMORIAL_REMINDER_SIGNUP_ENABLED = true`, 서버 `.env` 의
  `REMINDER_SCHEDULER_ENABLED=true`. 휴면 해제 후 30일 안에 관리자 번호로 시험 발송 한 번.
