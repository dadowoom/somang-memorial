# 소망교회 추모관 개시 전 운영 기준

이 문서는 기능 설명서가 아니라, 서비스가 오래 안전하게 운영되기 위한
기준이다. 비밀번호, 서버 주소, 데이터베이스 주소와 같은 비밀값은 이
문서나 저장소에 적지 않는다.

## 현재 운영 단위

- 키오스크와 웹은 같은 API와 MySQL 데이터베이스를 사용한다.
- 사진 파일은 현재 서버의 업로드 저장소에 보관된다.
- 공개 추모관은 `published` 상태이면서 `public` 공개 설정인 경우에만
  일반 웹 목록과 검색에 표시된다.
- 소망교회 성도는 회원가입 후 자유롭게 이용한다. 새 추모관은 관리자 확인 없이
  `published` 상태로 완성하며 회원이 선택한 공개 범위를 유지한다 (2026-09-15 결정).
  부모님 찾기로 만드는 추모관은 우선 비공개로 완성하고 가족이 공개 범위를 정한다.
  기존 `pending` 자료와 관리자가 내린 자료는 이 변경으로 자동 게시하지 않는다.
- 새 편지는 바로 `published` 상태로 게시한다 (2026-09-04 결정). 관리자는
  부적절한 편지를 사후에 `hidden` 으로 숨긴다. 같은 곳에서 반복 작성은
  요청 제한으로 막는다.

## 개시 전에 완료해야 하는 외부 운영 작업

1. [x] HTTPS 도메인을 연결하고 HTTP 접근은 HTTPS로 보낸다. (2026-09-13)
2. [x] 앱 포트는 외부에 직접 열지 않고, HTTPS 역방향 프록시만 외부에
       노출한다. (2026-09-13, 옛 3050 포트 닫음)
3. [x] 서버 관리자 계정과 데이터베이스 관리자 계정의 기존 비밀번호를
       교체한다. (서버 root 2026-08-11 교체·SSH 키만 허용 확인 2026-09-14.
       DB 관리자 비밀번호 교체 여부는 서버 담당자 메모에 따른다.)
4. [x] 앱에는 MySQL root 계정이 아닌 추모관 전용 제한 계정을 사용한다.
       (2026-09-14 운영 설정에서 확인)
5. [ ] 매일 데이터베이스 백업, 업로드 파일 백업, 복구 확인 일정을 만든다.
       → 백업은 매일 04:37 암호화 원격 저장소로 간다(30일 보관). **복원 리허설은

6. [x] 서버 응답, 디스크 사용량, 백업 실패를 알려 주는 외부 감시를 둔다.
       (2026-09-14: 서버 공용 감시가 하루 두 번 사이트 응답·백업 성공 기록·디스크·
       인증서·재시작 횟수를 보고 텔레그램으로 알린다)
7. 키오스크 PC는 일반 Windows 화면이 아닌 전용 전체 화면 모드로

   마쳤다 (#88, `docs/CHROME_KIOSK_HANDOVER.md`).

## 이용자가 늘어날 때의 확장 순서

1. 이미지 파일을 서버 디스크에서 객체 저장소로 옮긴다.
2. 요청 제한을 메모리 방식에서 Redis 같은 공용 저장소 방식으로 바꾼다.
3. 추도일 문자 발송 작업에 데이터베이스 잠금을 추가해 서버가 여러
   대여도 한 번만 발송되게 한다.
4. 읽기 요청이 많아지면 앱 서버를 여러 대로 늘리고, 앞단에 로드밸런서를
   둔다.

## 등록과 사후 관리

1. 사용자가 기념관 또는 편지를 작성한다.
2. 새 추모관은 관리자 확인 없이 바로 완성된다. 공개를 선택하면 검색과
   키오스크에도 표시되며 비공개를 선택하면 입장 비밀번호가 필요하다.
3. 관리자는 게시된 추모관을 사후에 관리한다. 관리자가 내린 자료의 게시 상태를
   회원이 바꿀 수 있는 권한은 부여하지 않는다.
4. 편지는 바로 게시되며, 관리자가 부적절한 편지를 사후에 숨긴다.
5. 게시 중인 기념관도 만든 회원이 글과 사진을 직접 고친다 (2026-09-12 결정).
   서버가 감사기록을 남기므로 관리자는 회원 화면의 감사기록에서 사후에
   확인한다. 게시 상태와 관리자 메모는 계속 관리자만 바꾼다.
   감사기록이 남는 일 (2026-09-14 기준): 회원 권한·상태 변경, 기념관 수정
   (관리자·유가족), 가족 초대 링크 발급·닫음, 가족 참여·제외·나감, 가족관
   만들기·제목 수정·비밀번호 변경, 편지 숨김·게시, 문자 알림 취소·복구, 회원
   탈퇴. 비밀번호·초대 링크 원문·전화번호 전체는 기록에 넣지 않는다.
6. 비공개 기념관은 비밀번호를 맞히기 전에는 성함·생년월일·소천일·요약을
   보여 주지 않는다 (2026-09-14 결정). 키오스크 검색에서 비공개 기념관을
   숨기는 것과 같은 기준이다. 입장 화면에는 "비공개 추모관" 안내만 나온다.

## 배포 전 확인

- 타입 검사, 자동 테스트, 운영 빌드가 모두 통과했는지 확인한다.
- HTTPS 주소, 키오스크 검색, 비공개 비밀번호, 편지 접수, 관리자 공개를
  실제 화면에서 확인한다.
- 배포 직전 DB 백업과 이전 앱 릴리스를 유지한다.
