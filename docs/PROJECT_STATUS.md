# 프로젝트 현황과 작업 인계

이 문서는 다른 PC나 새 작업에서 현재 상태를 빠르게 확인하기 위한 공개용
요약입니다. 비밀번호, 서버 접속정보, API 키와 보안상 민감한 상세 내용은 적지
않습니다.

- GitHub `main`: `1f069a7`
- 로컬 `main`과 GitHub `main`: 일치
- 2026-09-04 확인 기준 운영 버전과 `main`: 일치
- 자동 테스트: 176개 통과
- 실제 브라우저 주요 흐름 확인 완료
- 현재 열린 코드 변경 PR은 없으며, 이 문서 PR #29만 정리 중

정확한 최신 버전은 이 문서의 번호보다 GitHub `main`을 우선합니다. 작업을
시작할 때 반드시 원격 정보를 새로 받아 비교합니다.

## 다음 작업 순서

1. 가족관 비밀번호를 소유자와 관리자가 화면에서 안전하게 변경
2. 업로드 사진 용량을 자동으로 줄이는 방식 결정 후 구현
3. 비공개 입장 열쇠의 수명과 회수 기능 설계
4. 승인과 백업 후 기존 사진의 개인정보성 메타데이터 정리
5. 로그아웃 쿠키 경고 정리
6. 오래된 쿠키 자동 정리

현재 1번 작업은 코드 구조 조사와 구현안 설명까지 끝났고, 코드 수정은 아직
시작하지 않았습니다. 관리자 승인 후 별도 작업 브랜치에서 진행합니다.

## 협업 기준

- 시작: 최신 `main` 확인 → 진행 중인 PR과 겹침 확인 → 작업 브랜치 생성
- 종료: 코드 검사 → 테스트 → 빌드 → 브랜치 push → PR 작성
- 병합: 관리자 승인 후 진행
- 배포: 관리자가 명시적으로 요청한 경우에만 진행
- 인계: PR에 변경사항, 검사 결과, DB 영향, 배포 여부, 남은 일을 기록

새 PC 설치와 Git 사용법은 [README.md](../README.md), Codex의 세부 안전 규칙은
[AGENTS.md](../AGENTS.md)를 확인합니다.

- 운영 서버와 분리된 외부 백업 보관처

위 항목의 계정정보와 비밀값은 저장소에 넣지 않습니다.
